# check_billing_sep_01

`server.js` starts a Node.js HTTP server that answers every request, on any method and any path, with `Hello, World!`.

## Install

Nothing to install: the repository has no dependencies, and Node.js alone is required.

## Run

```sh
node server.js
```
The server listens on port 3000; open http://127.0.0.1:3000/ to reach it.
