# check_billing_sep_01

Run `npm install` first, then start the service with `npm start` (or directly with `node server.js`), or under PM2 with `npx pm2 start ecosystem.config.js`.

Environment variables: `PORT` (default `3000`), `HOST` (default `127.0.0.1`, used only in the startup log line), `MESSAGE` (the response body, default `Hello, World!\n`).
